Built 15 Nov 2026: `animate/tools/openverse.py` fetches CC BY / CC0 / public-domain instrumental tracks from Openverse (mostly Jamendo). Only the tool is tested. Whether YouTube raises Content ID claims on these tracks is **unknown** (status: NOT TESTED as of 15 Nov 2026).

**Why:** Bryan makes films in parallel: `riset-sekitar` gives 5 ideas, 3 go into 3 separate chats at once, the other 2 later. Chats cannot see each other, so if Openverse music goes into all of them before a result exists, one claim hits every film.

**How to apply:** `sekitar` films never use it (they synthesise their own bed, no licence needed). Use Openverse music only when Bryan asks, and only on ONE film until he says the test cleared. Before any film, try the cheap check: upload a short clip with the track as private on @rupanya.gini and read the "Checks" step / copyright tab in Studio. When the result is known, update this file (cleared / claimed, and which track). See [[project-konten-edukasi-sekitar]] and [[project-animate-skill]].
