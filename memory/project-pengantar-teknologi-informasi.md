Pengantar Teknologi Informasi (LAB), Kamis 09–12, UKSW Digital Business semester 1. Slides are bilingual (Indonesian with English gloss).

**Chapter 1 — delivered 3 September 2026** (class let out early). Topics:
- *Pengertian* — TI defined per Williams & Sawyer (2003): computing combined with high-speed communication lines carrying data, voice, and video. Data vs information; the DIKW triangle (Data → Information → Knowledge → Wisdom).
- *Komponen TI* — hardware, software, brainware.
- *Macam-macam TI* — teknologi masukan (input), mesin pemroses, teknologi penyimpanan (memory), teknologi keluaran (output), teknologi perangkat lunak.
- *Klasifikasi* — by system function (embedded / dedicated / general purpose); by size (supercomputer → mainframe → minicomputer → workstation → microcomputer); client-server. Supercomputer = complex math at speed (Frontier, Fugaku, Lumi); mainframe = high-security bulk transaction processing.
- *Peran TI* — banking (ATM), education (e-learning: Zoom, Google Classroom, Moodle, UKSW's flearn), medical (EHR); also policing, e-commerce, product design.

**Chapter 3 — Hardware, delivered 24 September 2026** (deck "3.Hardware.pptx", course code DB 101). Topics:
- Sistem komputer = hardware + software + brainware; four device groups: input, process, output, storage.
- *Input* — keyboard (Serial, PS/2, Wireless, USB; QWERTY), pointing devices (mouse, touch screen, light pen, stylus, graphic tablet, joystick), scanner (flatbed vs handheld, compared to a photocopier).
- *Process* — processor/CPU (speed in GHz; parts ALU, Control Unit, Memory Unit); motherboard (processor socket, memory slot, PCI slot, chipset, BIOS, I/O and power connectors).
- *RAM* — DRAM (capacitor, needs refresh), SRAM (no refresh, faster), EDO RAM (older PCs), SDRAM (synced to system clock), RDRAM (Rambus, high bus speed, narrow data path).
- *Storage* — hard disk (magnetic platters, track and sector, read/write head); interfaces IDE, ATA, SATA (hot-swap).
- *Output* — softcopy (monitor LCD/TFT vs CRT, RGB; speaker) vs hardcopy (dot-matrix with carbon copies, inkjet, laser/toner, plotter).
- Slide 13 swaps two terms: it says seek time finds the sector and latency finds the track. Standard definition is the reverse — seek time moves the head to the right track, rotational latency waits for the sector to spin under it. Flagged to Bryan 24 September 2026.
- In-class questions: why QWERTY? which connector is SATA vs ATA? Group activity: choose input/process/output hardware for a startup doing content design, customer-data processing, online meetings, and document printing, with the business reason.
