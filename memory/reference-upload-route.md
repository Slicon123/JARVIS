Learned while scheduling kartu, helm-jatuh and bensin-lama on 3 Nov 2026 (see [[project-konten-edukasi-sekitar]]). **Since 3 Nov 2026 the working procedure is the `unggah-sekitar` skill** (built at his request after the jentik-bak upload; local, not pushed); these notes are the history behind it. Its `prep.py` cuts the film into ≤9 MB parts (3 calls per platform instead of 6), and the SHA-256 is compared inside the page, because the Chrome tool blanks long hex strings it returns.

- **Files over 10 MB:** Chrome's `file_upload` refuses more than 10 MB per call, and a browser_batch counts all its uploads together. Split the mp4 with `split -n <k> -d` into ~5 MB parts in the scratchpad, add a hidden `<input type=file id=claude-stage>` to the page that stores each file in `window.__chunks`, upload one part per call, rebuild with `new File([...parts])`, compare its SHA-256 with `sha256sum` of the original, then set it on the site's own file input through `DataTransfer` and dispatch `change`. Worked on YouTube Studio, TikTok Studio and instagram.com. Staged parts are lost when the page navigates.
- **YouTube:** `youtube.com/upload` can open a channel that is not his content channel. Check the avatar is the orange "r." / Rupanya Gini before uploading, or go straight to `studio.youtube.com/channel/UCwBcNfWiZ7y3tolo-hnanuw/videos/upload?d=ud`. Custom thumbnails need the channel's phone verification (his to do; not done as of 3 Nov 2026); "Select from video" offers only 3 automatic frames. Schedule time is a 15-minute list; pick "(GMT+0700) Local Time". Type title/description with the type action, then compare SHA-256 of `#textbox` text with the upload.md block.
- **TikTok Studio:** the Draft.js caption reads back correctly as the `[data-block=true]` texts joined by `\n` (innerText adds extra blank lines). Cover: Edit cover → image input → Save (the Save button sits above the viewport in a short window; click it with JS). AI-generated content sits under "Show more". **Scheduled posts can't be edited**, so settle everything before pressing Schedule.
- **Instagram:** instagram.com has no schedule option and no drafts. **Meta Business Suite is now the scheduling route:** he logged in on 3 Nov 2026 (portfolio Rupanya Gini, linked to IG rupanya.gini and the Facebook Page). Tested the same day with jentik-bak up to the Schedule picker and discarded at his word ("tes aja, jangan upload beneran"); Scheduled and Drafts were empty afterwards. Its Add Video makes a file input only on click, so `stage.js` intercepts the click to avoid the native picker. First real schedule 3 Nov 2026 (arus-banjir, 19.00): caption read-back = the `[data-block=true]` texts joined by `
` (matched `instagram` 935; innerText reads 5 more, one extra newline per paragraph). Thumbnail: click the "Upload image" tab, then the "Upload image" link inside it; `stage.js` catches that input (`accept=image/*`) in `window.__picked`, then set `cover.jpg` from the stage chunks. Time fields are spinbuttons (hours, minutes, meridiem): click each and type `07`, `00`; read back with `aria-valuenow`. The Scheduled list is at `business.facebook.com/latest/posts/scheduled_posts`, one row per platform. Steps are in the `unggah-sekitar` skill.
- **Posting live (jentik-bak, 3 Nov 2026):** Chrome's YouTube may be signed in to his personal Google account; Studio then says "you don't have permission". Fix: youtube.com avatar → Switch account → Rupanya Gini (under the backup Google account). TikTok "Post" asks "Continue to post?" while Content check lite runs; after posting it shows "Only me / Content under review" for a few minutes, then Everyone. instagram.com Create → Post opens a crop that is not 9:16: pick Original. The caption counter under the box (e.g. 808/2,200) is the reliable length check; the DOM drops blank lines. Web has no Share-to-feed toggle; Share to Facebook Page defaults on. First comments: YouTube watch page, IG reel page, TikTok video page (open the comments panel, then click the box itself before typing).
- **Pinning first comments (tried 4 Nov 2026 on uang-kecuci and tutup-pulpen):** none of the three works from the web. YouTube: the comment's three-dot menu has Pin, but it opens "Get advanced features" and demands one-time YouTube Studio verification (phone, his to do; same block as thumbnails), so posted but unpinned. TikTok: the video page's menu and the Studio comments page (`tiktokstudio/comment`) offer only Delete/Reply/Like, no Pin; probably app-only. Instagram: the web menu (hover the comment, then the dots beside Reply) shows only Delete/Cancel, no Pin. Click Cancel by ref, never by coordinate: Delete sits right above it. Also: TikTok's like-notification toasts cover the comment box, so close them first. IG's comment panel keeps saying "No comments yet" after posting until the page reloads; reload to verify rather than posting twice.
- **Facebook Reels (4 Nov 2026):** a reel posted live on instagram.com did NOT produce a Facebook copy, even with Share to Facebook Page on: `business.facebook.com/latest/posts/published_posts` listed uang-kecuci and tutup-pulpen once each (Instagram icon only), while arus-banjir (scheduled in Business Suite to both) had one row per platform. So a Facebook Reel exists only when scheduled or posted through Business Suite's Create reel with both platforms ticked. A published row's first-comment box is in its detail page (Feed preview, "Add a comment…"); that detail page is per platform, so check the row's icon first.
- **Facebook-only reel via Business Suite (4 Nov 2026, uang-kecuci and tutup-pulpen, Share now):** Create reel → Post to dropdown → untick the Instagram row (it defaults to both; leaving it ticked would double-post to IG). Same `stage.js` route, `__put()` after Add Video. The Facebook composer's box is labelled Description (not Text); read-back = `[data-block=true]` joined by newline = `instagram` expect (679 / 727 matched). Thumbnail: Choose suggested needs an explicit click on the first frame to select it; for a named frame use Upload image: click the link (stage.js catches `accept=image/*` in `__picked`), `file_upload` cover.jpg into claude-stage, then set `__chunks['cover.jpg']` on `__picked`. Facebook runs a copyright check ("may have found copyrighted content" for a few seconds, then "No copyright issues"). Share shows "Reel processing"; the reel appeared in Published about 1 to 3 minutes later. First comment: the Business Suite detail page has no comment box; use its "View reel on Facebook" button (first click only scrolls, the second opens a new tab at facebook.com/reel/<id>), open the comment bubble, type, Post comment. Facebook's own comment menu has only Edit/Delete: no Pin either.
- **Phone (Samsung A36, shown as "Bryan's A36"):** PowerShell `Shell.Application` → Namespace(17) → "Bryan's A36" → Internal storage → Movies → `CopyHere`, then check `ExtendedProperty("System.Size")` against the original bytes.
