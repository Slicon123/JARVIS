When making latihan soal or a practice test for a course, copy the structure of the dosen's earlier tugas: the same petunjuk block, numbering, question wording and sub-parts. Change only the numbers, names and context. The answer key follows his own jawaban files: Diketahui → Ditanya → Langkah → Jawaban akhir, plus a Penjelasan note that is not copied onto paper. If a topic has never appeared in a tugas, base it on the exercises and examples in the slides, and tell him that's what you did. Work within any limit he gives on sub-parts, e.g. "maksimal a, b".

**Why:** On 7 Oct 2026 he rejected a first Matlog practice set that used my own question styles, and asked for it to be redone to match Tugas 1–2. The test should feel like the dosen's tugas.

**How to apply:** Read the soal PDFs and jawaban files under the course's `Tugas\` folder before writing a single question. Verify every computed answer. Also: when he says something "ke ubah", re-read the file and fix only the damage, such as text accidentally cut and pasted mid-line. Related: [[project-matematika-logika-db103a]].
