Recommended to Bryan on 2026-09-04 as a "fun and useful" project: a single self-contained
HTML file (same shape as [retro-shooter.html](../retro-shooter.html)) simulating an ATS
(automatic transfer switch) panel sequence and a fire alarm/suppression sequence — PLN
outage → sensing delay → genset crank → transfer → retransfer → cooldown; and
detector → panel → alarm verification → suppression release countdown/abort.

**Why:** His own career research ([[project-post-graduation-career-target]]) flags that his
technical depth in ATS/FSS is a real gap, not a strength, for the BD/Bid Manager target role —
he writes documentation for systems he's never operated ([[user-bryan-profile]]). Building a
simulator forces him to source and understand real timer values and interlock logic to make
it animate correctly, and the resulting state diagram doubles as a reusable flowchart for
[[project-fss-ats-documentation]]. He hasn't started it yet as of 2026-09-04.

**Condition set when proposed:** sequence timings/logic must come from actual specs/standards,
not recalled/invented — he can't catch a wrong figure ([[feedback-self-correct-and-verify]]).

**How to apply:** He asked to be reminded about this the next day (2026-09-05). If he hasn't
mentioned it, bring it up once, briefly — don't nag if he's clearly moved on to something else.
