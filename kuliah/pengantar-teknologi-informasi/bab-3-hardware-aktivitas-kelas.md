# BAB 3 Hardware — Aktivitas Kelas: Pilih Hardware untuk Bisnis

Jawaban untuk slide terakhir (hal. 19) deck *3.Hardware.pptx*, Pengantar Teknologi
Informasi, 24 September 2026. Teks dalam *(kurung miring)* adalah arti istilahnya —
boleh ikut diucapkan kalau dosen bertanya.

**Kasus:** sebuah startup butuh perangkat untuk desain konten (brosur, video, poster),
pengolahan data konsumen, rapat daring, dan pencetakan dokumen.

---

## 1. Input

- **Keyboard & mouse:** mengetik data konsumen dan mengedit desain.
- **Graphic tablet + stylus** *(papan untuk menggambar pakai pena, gambarnya muncul di layar)*:
  desain brosur dan poster jadi lebih presisi.
- **Scanner flatbed** *(seperti mesin fotokopi: kertas ditaruh di atas kaca lalu dipindai)*:
  memasukkan dokumen fisik seperti formulir dan kontrak ke komputer.
- **Webcam & mikrofon:** untuk rapat daring.

## 2. Proses

- **Processor dengan GHz tinggi** *(otak komputer; makin tinggi GHz, makin cepat berpikir)*:
  render video dan olah data butuh banyak perhitungan.
- **RAM besar** *(seperti meja kerja; makin besar, makin banyak aplikasi bisa dibuka bersamaan)*:
  supaya aplikasi desain, Excel, dan Zoom lancar dipakai sekaligus.
- **Hard disk SATA** *(hard disk = lemari arsip untuk menyimpan file; SATA = jenis kabel
  penghubungnya, lebih cepat dari yang lama)*: kapasitas besar untuk file desain dan data
  konsumen. Bisa **hot-swap** *(diganti saat komputer masih menyala)*, jadi kerja tidak terhenti.
- **Aplikasi:** Canva/Adobe untuk desain, Excel untuk data konsumen, Zoom/Meet untuk rapat,
  Word untuk dokumen.

## 3. Output

- **Monitor LCD TFT** *(layar datar yang warnanya lebih tajam dan akurat)*: supaya warna
  desain di layar sama dengan hasil cetaknya.
- **Speaker:** untuk suara saat rapat daring.
- **Printer laser** *(pakai tinta bubuk/toner, cepat dan murah per lembar)*: untuk mencetak
  banyak dokumen kantor.
- **Printer inkjet** *(menyemprotkan tinta cair, bagus untuk warna)*: untuk brosur dan poster
  berwarna.

## 4. Alasan bisnis

- **Sesuai kebutuhan:** setiap perangkat punya tugas yang jelas.
- **Performa:** anggaran terbesar untuk processor dan RAM, karena desain dan video adalah
  pekerjaan paling berat.
- **Saling terhubung:** alur input → proses → output → penyimpanan harus lancar semua. Kalau
  satu lambat, semua ikut lambat.
- **Hemat biaya:** beli yang perlu saja. Contohnya, **plotter** *(printer raksasa untuk banner)*
  tidak perlu dibeli kalau jarang dipakai.

## Kesimpulan

Hardware yang tepat membuat kerja startup lebih cepat, hasilnya lebih bagus, dan biayanya
tetap efisien.
